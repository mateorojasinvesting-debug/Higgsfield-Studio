# Hook Bank — Accesify

A growing library of opening hooks (first 1-3 seconds of a video, or first headline of an image) tested or proposed for Accesify creatives. Each hook is tagged by angle and the platform where it's expected to work best.

After each campaign runs, `/learn` updates this file with actual CTR/retention data, marking hooks as **proven**, **promising**, or **buried**.

## Angle taxonomy

| Angle | Triggers | Best for |
|---|---|---|
| **Engineering** | Curiosity about how it works, materials, specs | Premium-aware buyers, MeLi listings |
| **Status** | Self-image, aesthetic alignment, Apple ecosystem pride | IG feed, lifestyle Reels |
| **Functional** | Solving a real pain (lose AirPods, drop them, can't find them) | TikTok with retargeting, Meta |
| **Curiosity gap** | "What happens when…" reveal hooks | TikTok cold, organic IG Reels |
| **Social proof** | Reviews, "thousands chose this" (use only when true) | Bottom of funnel, retargeting |
| **Price** | Premium-but-justified, not discount | MeLi titles, conversion-stage ads |

## Pulse FlickLock — proposed hooks (v1, untested)

### Engineering
- "Diseñado solo para AirPods Pro 3."
- "20.000 aperturas. Una sola mano."
- "Doble defensa. Una sola pieza."
- "TPU + policarbonato. 83 gramos. Sin compromiso."

### Status
- "Tu Apple merece su accesorio."
- "Apple no lo hizo. Pero se ve como si lo hubiera hecho."
- "Combina con todo. Excepto con lo genérico."

### Functional
- "Imán que abre solo. Cordón que sostiene. LED que avisa."
- "Find My, ahora con altavoces que sí dejas oír."
- "Lo abres con una mano. Aunque la otra esté ocupada."

### Curiosity
- "Esto le pasa al case después de 10.000 aperturas." *(reveal: nothing — still pristine)*
- "Lo abrimos 20.000 veces para que tú no tengas que pensarlo."
- "¿Cuántas veces lo abres al día? Esto fue diseñado para 20.000."

### Visual-only (no copy, image speaks)
- Macro of mint-green slider igniting LED — for IG Story / TikTok cold
- Magnetic lid floating open in slo-mo against black — for Reels
- Drop test slo-mo (case bouncing, unharmed) — for TikTok hook
